Práctica: Rutas y navegación de carpetas.

info_outline Rutas y navegación de carpetas.

Practicarás cómo moverte entre carpetas desde la consola y desde Python, y entenderás la diferencia entre una ruta estática (absoluta) y una ruta dinámica (relativa), para que tus programas funcionen en cualquier computadora.

group Modalidad

Individual, en laboratorio (tiempo estimado: 50 minutos).

check Objetivos de aprendizaje
  • Navegar entre carpetas desde la consola con cd y listar su contenido con dir o ls.
  • Identificar las diferencias de las diagonales (/ vs \) entre sistemas operativos.
  • Distinguir rutas estáticas de rutas dinámicas (relativas) y usarlas en programas de Python.
list Instrucciones
  • Parte 1: La consola
    Abre una terminal (CMD o PowerShell en Windows; Terminal en macOS o Linux) y resuelve lo siguiente.
  • 1. Cambiar de carpeta con cd. Ubícate en tu carpeta de documentos, entra a una subcarpeta y regresa un nivel con cd ... 
    cd Documents
cd proyecto
cd ..
  • 2. Ver el contenido de una carpeta. Usa dir en Windows o ls en macOS y Linux. 
    dir      (Windows)
ls       (macOS / Linux)
  • 3. Las diagonales según el sistema operativo. Windows separa las carpetas con \ (diagonal invertida); macOS y Linux usan /. Escribe en tu cuaderno la ruta de tu carpeta actual y observa qué diagonal aparece. Python en Windows acepta ambas, pero \ tiene un significado especial dentro de las cadenas (por ejemplo "\n" es un salto de línea), por eso en Windows se escribe r"C:\Users\Name" (cadena cruda, con la r al inicio) o se usa /.
  • 4. Espacios en los nombres de carpeta. Intenta entrar a una carpeta llamada mis documentos sin comillas y observa el error. Luego usa comillas: 
    cd mis documentos       (error: la consola cree que son dos argumentos)
cd "mis documentos"     (correcto)
  • 5. Rutas estáticas vs. dinámicas. Compara estas dos formas de indicar el mismo archivo: 
    "c:/mis documentos/proyecto/prog.py"      (ruta estática o absoluta)
"proyecto/prog.py"                        (ruta dinámica o relativa)
    ¿cuál de las dos funcionaría si copias tu proyecto a la computadora de un compañero? ¿Por qué?
  • Parte 2: Rutas desde Python
    6. Cambiar de carpeta desde un programa. Ejecuta el siguiente código (cambia la ruta por una que exista en tu computadora) y explica qué imprime en cada paso. 
    import os

print("Original:", os.getcwd())

# cd (es necesario usar r"" en Windows)
os.chdir(r"C:\Users\Name\Documents")

# cd ..
os.chdir("..")

print("Nueva ubicacion:", os.getcwd())
  • 7. Abrir un archivo con ruta relativa. Crea la carpeta datos junto a tu programa, guarda dentro un archivo notas.txt y escribe un programa que lo muestre en pantalla usando una ruta relativa: 
    archivo = open("datos/notas.txt", "r")
print(archivo.read())
archivo.close()
    Ahora ejecuta el programa desde otra carpeta (con cd). ¿Sigue funcionando? ¿Por qué?
